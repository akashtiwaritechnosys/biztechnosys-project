The Content Delivery role

The Content Delivery (CD) role is central to powering visitor experiences across all channels. Its primary function is to deliver rendered, personalized content to users on websites, apps, and other media platforms.

Content delivery relies on three key roles and an index:

Content Delivery role.

Accurately measure marketing ROI.

Core database

Web database

Web index

When a visitor accesses the CD role through a browser or mobile app, it retrieves content and media from the Web database and returns a fully rendered page. Additionally, the business logic within the CD role can leverage the Sitecore Content Search API, which uses the Web index to enable fast, query-based content retrieval

Read More
Scaling content delivery

To handle heavy traffic or ensure failover, the Content Delivery (CD) role can be scaled across multiple servers or cloud services to form a cluster. Scaling can also extend across multiple data centers or geographic regions to minimize website latency. In such scenarios, it is recommended to host both the Web database and the Core database within each data center, thereby reducing latency between the CD roles and their associated databases.

Privacy and security

Each of the Sitecore components contains a number of logical entities that together with a number of cloud services form the entire functionality of the Sitecore platform.

Sitecore Experience Manager

XM refers to the web content management (WCM) core of the Sitecore Experience Platform. It encompasses the features for creating, managing, personalizing, and publishing content. (The specific features available depend on the type of XM installation.) XM is composed of a subset of the logical roles within the platform

Sitecore Experience Platform

XP extends XM by integrating marketing and customer intelligence features through xConnect and xDB. These components introduce additional server roles and storage mechanisms.

xConnect is a set of services that act as an intermediary between xDB and any trusted client, device, or interface that needs to collect or query experience data over HTTPS.

xDB is a collection of services and storage roles responsible for storing and processing experience data. External clients, such as a Content Management server, must use xConnect to read from or write to xDB
